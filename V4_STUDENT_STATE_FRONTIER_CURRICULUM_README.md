# Crossy V4 Student-State Frontier Curriculum

This experiment keeps the full MaleCNS and the selected MLP64 decoder architecture, but changes where supervision comes from.

The exact-seed branch curriculum used recurrent states produced by teacher prefixes. The recurrent-state audit showed that truncating history can help slightly, but not decisively: full stateful remains strong and reset is clearly destructive. The remaining mismatch is therefore attacked directly.

Each round now:

1. Runs the current best student statefully on `crossy-v4-expo:0006`.
2. Saves the **actual MaleCNS recurrent states generated by the student's own history**.
3. Prioritizes the terminal frontier, unsafe/unacceptable decisions, and one-choice critical states.
4. Adds planner supervision at those exact hidden states.
5. Rolls short planner recovery branches from those same student hidden states.
6. Fine-tunes the current MLP64 with a low learning rate.
7. Accepts the candidate only if exact-seed performance improves (real success, score, then steps).
8. Extends teacher anchors only a small distance beyond the current student frontier, avoiding deep teacher-state data that previously damaged early closed-loop behavior.

The MaleCNS remains completely frozen and fully recurrent.

```powershell

```

Defaults: 8 rounds, 18-frame frontier tail, at most 32 roots, 3 recovery branches/root, 10-step branch horizon, 60 decoder epochs/round, LR 0.0015. Training stops early after two rounds without exact-seed improvement.

Outputs:

```text

  best_decoder.pt
  round-1.pt
  ...
  report.json
```
