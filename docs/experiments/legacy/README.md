the repository root. They describe the commands, paths and assumptions of
their original experiments, not the current installation's required setup.

[ACTIVE_CONTEXT.md](../../ACTIVE_CONTEXT.md). For the full-neuron checkpoints
kept outside Git, see [TRAINING_ARTIFACTS.md](../../TRAINING_ARTIFACTS.md).

versioned cached-frontier scripts now live in
[scripts/experiments/cached_frontier](../../../scripts/experiments/cached_frontier/).

[run-index.json](../run-index.json). Existing curated audit files in `reports/`
retain their original paths so historical references remain usable.
