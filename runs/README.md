# Local training runs

Place external checkpoints, resumable training state, datasets and generated
reports here using their original run-directory names. Everything below this
directory except this README is ignored by Git.

The cleanup leaves existing local files in place. A new checkout contains only
this README; it does not download a teammate's training artifacts.

See [external training artifacts](../docs/TRAINING_ARTIFACTS.md) for sharing,
restoring historical reports and regenerating the exported expo.
