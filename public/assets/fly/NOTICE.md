# Fly model attribution

The runtime fly model is a modified derivative of **“Fly” by jeremy**,
downloaded from Poly Pizza:

- Source: https://poly.pizza/m/f8kM9xA_5sV
- Author: jeremy
- Original format: OBJ/GLTF
- License: Creative Commons Attribution (CC BY)
- Poly Pizza listing date: 2017-10-20

Project modification:
the original GLB's cyan wing geometry was split into left and right meshes,
each attached to its own named pivot (`wing-left-pivot` and
`wing-right-pivot`) so the game can fold and animate the wings independently.
The body geometry/material groups otherwise retain the source model's
low-poly structure.

Attribution is retained here because the source model requires it.
