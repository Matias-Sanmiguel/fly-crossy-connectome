# Kenney 3D assets

The 43 GLB files and their four required colormap textures in this directory
are unmodified selections from Kenney's City Kit (Roads), Car Kit, Train Kit,
Nature Kit, and Survival Kit packs. Kenney releases these assets under Creative Commons CC0
1.0 Universal.

Attribution is not required by CC0, but this project records the original pack,
upstream archive hash, upstream path, local byte count, and local SHA-256 in
`manifest.json` so the shipped asset set remains auditable.

Sources:

- https://kenney.nl/assets/city-kit-roads
- https://kenney.nl/assets/car-kit
- https://kenney.nl/assets/train-kit
- https://kenney.nl/assets/nature-kit
- https://kenney.nl/assets/survival-kit
- https://creativecommons.org/publicdomain/zero/1.0/

Rail crossing warning bodies use `road-sign-stop.glb` from Kenney City Kit Roads; the red warning lamp is rendered separately so only the lamp blinks.

Nature Kit scenery intentionally excludes palm assets. Selected grass obstacles are authoritative blockers; the dense tree line outside the playable columns is visual boundary scenery.
