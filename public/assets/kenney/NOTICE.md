# Kenney 3D assets

The 37 GLB files and their five required colormap textures in this directory
are unmodified selections from Kenney's City Kit (Roads), Car Kit, Train Kit,
Mini Forest, and Survival Kit packs. Kenney releases these assets under Creative Commons CC0
1.0 Universal.

Attribution is not required by CC0, but this project records the original pack,
upstream archive hash, upstream path, local byte count, and local SHA-256 in
`manifest.json` so the shipped asset set remains auditable.

Sources:

- https://kenney.nl/assets/city-kit-roads
- https://kenney.nl/assets/car-kit
- https://kenney.nl/assets/train-kit
- https://kenney.nl/assets/mini-forest
- https://kenney.nl/assets/survival-kit
- https://creativecommons.org/publicdomain/zero/1.0/

Rail crossing warning bodies use `construction-light.glb` from Kenney City Kit Roads; the red warning lamp is rendered separately so only the lamp blinks.
